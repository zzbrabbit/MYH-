⚠️ 重要须知（上线前必读）

关于产品数据：本网站是纯静态网站，数据存储在浏览器本地（IndexedDB）。 这意味着你在后台添加/修改的内容，只在你当前使用的浏览器中可见， 其他访客打开网站时，看到的仍是网站内置的默认内容。

正确的使用方式：在后台管理好内容后，点击 "Publish to Website" 按钮， 浏览器会下载 data.js（含全部数据与图片），用它替换网站根目录的同名文件后重新部署， 即可让所有新访客看到你发布的内容（图片也一并保留在数据中）。
关于联系表单：表单提交目前是模拟的（显示成功提示，但不发送真实邮件）。 如需接收客户询盘，建议接入第三方表单服务（如 Formspree、EmailJS）或更换为后端接口。
关于社交媒体链接：页脚的社交媒体图标目前是 # 占位符， 上线前请替换为你真实的 Instagram/Facebook/LinkedIn/YouTube 链接。
关于后台安全：前端认证（djb2 哈希）安全性有限，技术上可被破解。 但对于企业官网的产品管理后台，风险可控。如需更高安全性，建议增加后端认证。

方案一：Netlify免费

最适合人群：不想折腾代码、希望最快上线的用户

优点：免费、自动 HTTPS、全球 CDN、自定义域名、拖拽上传

操作步骤：

1
注册 Netlify 账号
打开 https://app.netlify.com，用邮箱或 GitHub 账号注册（免费）
2
进入网站目录
打开文件夹 C:\Users\Andrew\WorkBuddy\2026-07-20-08-17-06\website
3
拖拽上传
在 Netlify 控制台找到 "Sites" → 点击 "Add new site" → "Deploy manually"
将 website 文件夹里面的所有文件（不是文件夹本身）拖到上传区域
注意：不要拖 server.js 文件，它不需要上传
4
等待部署完成
几秒后你的网站就上线了！Netlify 会给你一个类似 https://sparkling-unicorn-12345.netlify.app 的网址
5
分享给客户
将这个网址发给客户即可点击访问
后续更新：每次修改网站后，在 Netlify 控制台点击 "Deploys" → 拖入新文件即可更新，无需重新创建。

方案二：Vercel免费

最适合人群：有 GitHub 账号、希望自动部署的用户

优点：免费、自动 HTTPS、全球 CDN、每次推送自动更新

操作步骤：

1
将网站上传到 GitHub
在 GitHub 创建一个新仓库（如 myhbeauty-website），将 website 文件夹里的所有文件上传到仓库
2
注册 Vercel
打开 https://vercel.com，用 GitHub 账号登录
3
导入项目
点击 "New Project" → 选择你的 GitHub 仓库 → 点击 "Deploy"
Framework Preset 选择 "Other"（因为是纯静态网站）
4
部署完成
获得 https://myhbeauty-website.vercel.app 网址，以后每次更新 GitHub 代码，Vercel 自动重新部署

方案三：GitHub Pages免费

最适合人群：熟悉 Git 的开发者

优点：完全免费、版本控制、自定义域名

限制：网站必须是公开仓库（免费版）

操作步骤：

1
创建 GitHub 仓库
仓库名建议为 myhbeauty（如果要用 GitHub Pages 自定义域名，建议用 用户名.github.io）
2
上传网站文件
将 website 文件夹里的文件（不含 server.js）上传到仓库根目录
3
开启 GitHub Pages
仓库 Settings → Pages → Source 选择 main 分支 → / (root) → Save
4
等待激活
几分钟后访问 https://用户名.github.io/myhbeauty/

方案四：国内托管国内加速需备案

最适合人群：主要客户群在中国的企业

优点：国内访问速度快、可绑定 .cn / .com 域名

缺点：需要 ICP 备案（约 1-3 周）

选项 A：腾讯云 COS 静态网站托管

1
注册腾讯云账号，开通 对象存储 COS
2
创建存储桶，权限设为"公有读私有写"
3
上传 website 文件夹内所有文件到存储桶
4
在存储桶"基础配置"中开启"静态网站"，设置索引文档为 index.html
5
通过 COS 域名访问，或绑定自定义域名（需备案）

选项 B：阿里云 OSS 静态网站托管

操作类似腾讯云 COS，在阿里云控制台开通 OSS → 创建 Bucket → 上传文件 → 开启静态网站托管。

🔗 绑定自定义域名

如果你希望客户访问 www.myhbeauty.com 而不是平台子域名，可以绑定自己的域名：

1. 购买域名

在域名注册商购买域名（推荐）：

  • 海外：Namecheap、Cloudflare、GoDaddy（.com 约 ¥80-100/年）
  • 国内：腾讯云、阿里云（.com 约 ¥55-75/年，需实名认证）

2. 在托管平台添加域名

以 Netlify 为例：控制台 → 你的站点 → Domain settings → Add custom domain → 输入你的域名

3. 配置 DNS 解析

在你的域名注册商后台，添加 DNS 记录：

# 方式 A：CNAME 记录（推荐）
类型: CNAME
主机记录: www
记录值: your-site.netlify.app.

# 方式 B：A 记录（指向 IP）
类型: A
主机记录: @
记录值: 75.2.60.5  (以 Netlify 实际提示为准)

4. 等待生效

DNS 解析通常需要几分钟到几小时生效。Netlify/Vercel 会自动为你配置 HTTPS 证书（Let's Encrypt）。

国内域名：如果使用国内域名（.cn/.com.cn）并托管在国内服务器，必须先完成 ICP 备案才能访问。

📝 后续如何更新网站内容

更新产品（让所有访客看到）

因为网站是纯静态的，数据存在浏览器本地。要让所有访客看到你更新后的内容（产品/文章/海报/图片等）：

1
在后台管理好内容（产品/文章/海报/图片等）
2
点击后台右上角的 "Publish to Website" 按钮，浏览器会下载一个 data.js 文件（包含全部数据与图片）
3
用下载的 data.js 替换网站根目录下的同名文件（网站根目录已有占位文件）
4
重新上传整个网站文件夹到托管平台（Cloudflare Pages / Netlify 拖拽 / Vercel 推送 GitHub）
5
新访客打开网站即直接看到发布的内容（首次访问自动采用发布数据）；你自己浏览器的本地数据优先，不受影响
注意：如果你希望产品管理能实时同步给所有访客（无需重新部署），需要升级为动态网站（加后端数据库）。 推荐方案：Supabase（免费 PostgreSQL + API）或 Firebase（Google 免费数据库）。

修改文字内容

直接编辑对应的 HTML 文件（如 index.html、about.html），保存后重新上传即可。

修改颜色主题

打开 css/style.css，修改文件顶部的 :root CSS 变量：

:root {
  --c-accent: #1877F2;     /* 主色调 */
  --c-accent-d: #0F5BC4;   /* 深主色 */
  /* 修改这两个值即可全站换色 */
}
